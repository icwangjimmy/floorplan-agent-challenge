# 一张户型图到可编辑的 3D 家居空间

给支持原生看图和编程的 Agent 一张户型图、140 项 Kenney 素材及一份任务书，让它独立完成房屋重建、家具选配与网页编辑器开发。

这是文章的读者试跑材料，下载后用于让 AI 开发应用；其中没有做好的装修程序，也没有任何模型的参考答案。

## 三步开始

1. [下载 v1.0.0 完整 ZIP](https://github.com/icwangjimmy/floorplan-agent-challenge/archive/refs/tags/v1.0.0.zip) 并解压，也可以点击仓库的 Code → Download ZIP 下载最新版。
2. 按 [输入说明](INPUT.md) 放入自己的户型图。140 项本地素材已经在 `input/kenney-140-input-v1.zip`，无需再逐件下载。
3. 在一个干净目录中，将 `TASK.md`、户型图和素材 ZIP 交给 Agent，复制 [启动提示词](START.md) 开始。完成后按模型自己的 README 启动网页，再按任务书第 6 节检查。

需要：支持原生图像输入的模型；具备文件读写、终端和浏览器能力的 Agent；可安装 Node.js/项目依赖的本地开发环境。文章第一阶段使用 Hermes。换用其他 Agent 也能尝试，但运行框架会影响结果。

## 输入内容

```text
TASK.md
input/
  floorplan.png                 # 自行准备
  kenney-140-input-v1.zip        # 已附完整素材，约 0.94 MiB
```

素材 ZIP 包含 140 个 GLB、140 张缩略图、`catalog.json`、尺寸表、来源和许可。120 项是家具/设备/装饰，20 项是建筑构件。比例是本实验统一的建模假设，不是品牌商品的规格认证。

## 与文章实验的关系

本版沿用实验的功能、几何约定与评分权重，将预算统一写为最多 500 次请求、不设固定时间上限。它是便于读者试跑的版本，不替代文章保留的原始实验记录。读者换图后，可以比较同一张新图下的多次结果，不能直接沿用文中的分数。

如果用于模型比较：每个模型一个新目录、新会话，提供相同三份输入，禁止读取别人的代码与布局。记录模型版本、接口渠道、工具环境、请求数、用时和 Token。原生图片直接交给主模型，不启用辅助视觉模型。

## 素材来源

家具来自 [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit)，原许可见 [KENNEY-LICENSE.txt](KENNEY-LICENSE.txt)。本包保留原几何和材质，统一比例并把定位点移至底面中心；加载时保持 `scale=[1,1,1]`。原始户型图不在分享包内，读者使用自己有权使用的图片。
